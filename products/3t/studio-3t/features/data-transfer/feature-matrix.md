## Formats confirmed absent

A source-code review of `t3/utils/export/` (2026-07-31) found no Parquet, Avro, YAML, standalone XML, or PDF import/export capability anywhere in the codebase — these are confirmed absent, not merely unverified. The supported format set remains CSV, JSON, BSON, Excel (.xlsx), SQL, and MongoDB-to-MongoDB. See [findings](../../../../../research/studio-3t-desktop-review-2026/06-data-transfer-findings.md).
