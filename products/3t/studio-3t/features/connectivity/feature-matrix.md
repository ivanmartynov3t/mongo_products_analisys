## Edition names (corrected 2026-07-31 per S5)

`utils/Edition.java` defines five `Edition` enum values and their actual display names: `PROFESSIONAL`/`CORE`/`PRO` all display as **Professional**, `ROBO` displays as **Community Edition**, `FREE` displays as **Free**, `ENTERPRISE` displays as **Ultimate**. There is no separately named "Pro/Base" tier — `PRO`/`CORE` are internal aliases for Professional. This table uses these corrected names throughout; "Pro/Base+" language has been retired.
