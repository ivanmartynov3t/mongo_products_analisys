## 4. Per-idea write-up structure (applied identically to all 10)

Each section will contain, in this order:

1. **One-line pitch** — what it is, in plain language.
2. **Confirmed absent from Studio 3T Desktop** — the specific dictionary sub-feature ID(s) (or "no ID exists yet") and the specific Tier A source (`feature-dictionary.md` coverage matrix, `gap-analysis-not-on-3t-desktop.md`, or `cumulative-report.md`) confirming the gap. No idea ships without this check passing.
3. **Why we recommend it** — synthesized evidence, written as findings not a citation dump: competitive pressure, customer/persona demand, market trend, and (where applicable) in-house precedent elsewhere in the 3T product family. Every factual claim keeps its source attribution inline (file name + short quote where the source is quotable), but framed as "here's what the evidence says," not "here's which stage found it."
4. **What it builds on** — existing Studio 3T Desktop capability it would extend (dictionary IDs), so the idea reads as additive, not a rewrite.
5. **Who it's for** — segment/persona, grounded in the persona research files where available.
6. **Why it's feasible** — origin tag (portfolio-port vs. net-new) explained concretely: which other 3T product already proves this works, if any.
7. **Score** — the Priority Score carried as a single number with a one-line basis, not a 5-row calculation table.
8. **Risk to flag** — one honest caveat per idea (kept from v1.0's "risks/open questions" sections), max 2-3 sentences.

Target length per idea: dense but bounded — enough to be "very detailed" without sprawling into re-derivation of the whole rubric.

## 6. Score integrity

Scores are **not** being re-derived from scratch. A score changes only if this pass's re-reading surfaces:
- A confirmed competitor capability that changes the competitive-framing tag (as happened to `idx-perf-advisor` in v1.0), or
- A confirmed absent/present fact that changes Build Effort (as happened to `webhook-notify` in v1.0), or
- New corroborating evidence strong enough to move Evidence Strength/Reach/Severity by the rubric's existing 1-5 definitions (in `01-research-plan.md`) — reused as-is, not rewritten, since the rubric itself isn't in scope for this revision.

Any such change will be reported as a plain fact in the idea's section ("previously scored 4.33; corrected to X because...") — one sentence, not a stage-audit narrative.
